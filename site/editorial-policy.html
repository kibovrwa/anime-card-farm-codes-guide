Editorial Policy

This is the rulebook for Anime Card Farm Wiki. It applies especially to codes, beginner, packs, and the reference hubs.

Mission

Help players redeem honestly labeled codes, start a first session without wasting currency, and evaluate packs with payback math — without fake “ALL WORKING” titles or invented odds.

Publishable claims

  • Primary — in-game UI a writer can see; Roblox experience listing metadata checked on a named date.
  • Dated public lists — usable as Contested candidates when they disagree with our table.
  • Methods — payback formulas, failure checklists, offline readiness steps that do not require secret numbers.

Evidence labels

LabelMeaningTypical use
ActiveRedeem confirmed on the check date or strongly supported by a primary surface we trust that dayCodes table
ContestedCredible sources disagree, or redeem failed for us while others report successCodes table
Expired / InactiveRedeem failed or listing removed with documentationCodes table
ReportedThird-party claim kept out of Active until primary agreesOdds, rumors
MethodPlayer procedure using your client numbersPacks, offline

What we will not invent

  • Working code lists padded with undated social posts.
  • Pack probability tables presented as official when no public official table exists.
  • Mutation multipliers, card DPS, or offline rates as studio facts from thin air.
  • Paid placement disguised as a beginner tip.

Title and honesty rules

We avoid “ALL CODES WORKING” when Contested rows exist. Pack titles prefer “payback” / “evaluate” language over “best pack guaranteed.” Checked dates appear on money pages when refreshed (for example October 15, 2026).

Review cadence

Codes aim for same-week freshness when the game is active; Saturday-style refresh habits on sister sites are the model. Mid hubs update when UI labels or economy routes change, not on a hollow daily rewrite.

Corrections

Email hello@animecardfarm.wiki with URL, wrong sentence, and evidence. Related: Source methodology, Contact.

Conflicts of interest

AdSense authorization does not buy Active labels. Staff/operator play accounts are not “verified influencer drops.”

Languages

English on animecardfarm.com is canonical. Locale hubs, if present, should not invent a different Active list.

Destruction of evidence

When a code moves to Expired, we prefer to keep it in an expired section with context rather than pretending it never existed. Silent deletion of Contested rows is not allowed.

Who can publish

Only operators with deploy access can change money tables. Community mail can propose changes; it cannot push production by itself. That protects Contested evidence from being overwritten by whoever shouts loudest in a Discord.

Style rules for money copy

  • Prefer short answer boxes above the fold.
  • Put the Checked date near the table, not buried in a footer only.
  • Name Contested sources when disagreement exists.
  • Keep redeem failure checklist adjacent to the table.

When we take a page down

We soft-retire guides that are wholly obsolete after a game rewrite, with redirects or clear banners when possible. We do not 404 trust pages to “clean” a review. Soft-404 trust clones are forbidden after the October 2026 audits.

Quotes and screenshots

Crop UI to the relevant label. Do not publish other players’ usernames or chat logs with personal data. Watermarked “exclusive leak” images without UI context are weak evidence.

Sourcing debt

If a mid hub still lacks primary confirmation, the page must say so in plain language (for example crafting recipe limits). Hiding uncertainty behind confident tone is an editorial violation.

Priority order when time is short

  1. Codes Active/Contested/Expired accuracy.
  2. Beginner sequence still matches the live UI.
  3. Packs payback examples not obviously rotten.
  4. Trust pages still reachable (no soft-404 regressions).
  5. Mid-hub polish.

Traffic vanity rewrites never outrank item 1.

Sample rejection notes (internal style, made public)

  • “Rejected: Active claim from undated TikTok mirror.”
  • “Rejected: pack odds table without official public source.”
  • “Accepted as Contested: redeem failed here; dated press list still shows working.”
  • “Accepted as method: payback formula using Shop labels.”

Publishing the rejection style keeps freelancers and future editors aligned without a private lore doc.
