How to redeem (in-game)

  1. Launch Roblox and join place ID 125039473548047 (Anime Card Farm / Anime Card Factory experience).
  2. Wait until the farm HUD finishes loading — do not paste while the shop is still spawning.

Why Contested exists (honesty rule)

Code sites copy each other and update on different days. On October 15, 2026:

  • Active — at least two independent current lists still show the string as working, and no dated source we checked marks it expired after that agreement.
  • Contested — lists disagree (one Active, one Expired, or spelling forks). We show both sides instead of inventing a single “working” claim.
  • Expired — at least one dated source says it ended, and no list reports a successful redeem after that date.

If a code fails

  1. Expired or Contested that already died — compare with the table; lists lag real end dates by days.
  2. Already redeemed — one use per account is the normal rule.
  3. Typo / wrong case / missing ! — use Copy; TRAITS! ≠ TRAIT!; POTIONS usually has no !.
  4. Wrong UI — redeem is inside Shop, not the Roblox website code box for other experiences.
  5. Stale client — fully leave the experience and rejoin after a big update.
  6. Never existed — random TikTok strings with no reward evidence stay off this table on purpose.
